Guardrails

v1.1

The mechanisms that stop a specific failure from reaching you silently. Each one exists because something broke once. The test for adding a new one is simple: what failure does this catch? If it does not answer that, it belongs on Components, not here.

One source of truth. This list lives in a single file, guardrails.js, and is rendered from there on this page, on the Cheat Sheet, and on Components. Add a guardrail once and it appears in all three. That is itself the rule this page is about: where a value shows in more than one place, one place owns it and the rest read from it.
