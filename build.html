What this was

Components was the visual inventory of every piece of the operating system, grouped into live, backend and planned.

Why it was archived

It was archived on Aug 18 2026 because it had quietly gone stale. It still listed the Travel database and the QS ecosystem dashboard as planned long after both had shipped, so anyone reading it got a picture of the system that was months out of date. A page that describes the system and does not check itself is worse than no page.

Nothing was lost

The last published version of this page is kept verbatim in pages_archive, with the reason and the date. It can be restored at any time.
