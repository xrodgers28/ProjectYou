Features

What every lane, label and button on this page does.

The three lanes

  • ⚡ Code NowWhat we are building today. The lane a card sits in is its status, so moving it is the decision
  • 🌙 After MidnightThe batch to run this evening. Park work here through the day, then hand the lot over at night
  • 🅿️ Parking LotNot decided yet. Nothing here ever gets built until you move it into a lane (the overnight run also parks anything that looks already done)
  • Runs atWhat time the After Midnight batch is meant to run. Takes effect on the next run, not this one

Moving things around

  • ⠿Drag handle. Drag inside a lane to reorder, or straight across into another lane
  • ▲ ▼One slot at a time. At the end of a lane they carry on into the next one, so you can walk a card from Code Now down to the Parking Lot without dragging
  • move toSends the card straight to that lane. Same result as dragging, for when dragging will not play
  • 1Its place in the order. The numbering runs straight down the page through all three lanes, so 1 is the very first thing that gets built

Handing work over

  • ⚡ Code nowHands everything in Code Now to Claude. Free: it only marks the cards, nothing paid runs anywhere
  • 🌙 Hand overThe same, for tonight's batch. The two lanes fire independently
  • the wordsNothing starts on its own. Open Cowork and say run the Midnight Run queue, and Claude works the list in the order shown, with your repo and the live site in front of it
  • ✓ Already doneParking Lot only. Closes an item out without building it, for when it turns out it was done already
  • descriptionThe full task, as you dictated it or as Claude wrote it up. Click straight into it to edit, same as the note under a task on All ToDos. Saves when you click away
  • Show moreDescriptions are trimmed to three lines so the lanes stay scannable. The button only appears when there is more to see
  • ＋ add commentOn every card in every section. A note to yourself or to Claude, saved the moment you click out. Reads 💬 comment once it has one
  • 🔧 Needs a fixRaise a fix on any item. Say what is wrong and it becomes a Claude to-do under 🔧 Fixes to make on the All ToDos board. The card itself stays where it is

What a card is doing

  • no labelSitting in a lane, not handed over yet. Nothing is happening to it
  • ⏳ waitingHanded over, not started. It waits until you open Cowork
  • ⚙ buildingBeing worked on right now. The card glows so you can spot it in any lane
  • ✅ completeBuilt. Open View what was built on the card to read it
  • ⚠ FailedSomething went wrong. The reason is printed on the card in red

Counts, so you do not have to watch

  • lane badgeLive count beside each lane heading: ⚙ 2 building or ⏳ 3 waiting
  • browser tabThe tab itself reads the same count, so work in the background is visible from another tab entirely
  • RefreshRe-reads everything and re-crawls the live site. The page also polls on its own
  • savedTop right. Every drag, arrow and comment saves the moment you make it

Finished / Shipped, at the bottom

  • ▶ the caretThe section is a window shade, shut by default. Tap the heading to roll it down. It is always rolled up again next time you arrive, so finished work never gets in the way (shut, it does not even crawl the site)
  • put back intoPulls an item back out into any lane. Drag it out, or press ▲ on the top card. It stops being done and goes back to not handed over, ready to build again (what it built last time is kept in the database)
  • drop it backDragging a card down into the shade marks it shipped. Rolled up, it still shows a thin drop strip so you can do it without opening the section. Press ▼ on the bottom Parking Lot card for the same result
  • reversibleNothing here is one way. Anything marked shipped can be pulled straight back out into a lane
  • board:Where the item stands on the All ToDos board
  • live:Read off the real site, not a saved guess, so it shows what is actually deployed
  • draft pendingA newer draft exists that is not live yet
  • DeployFlags it as one you want shipped. Mark deployed closes it out once it is live
Nothing on this page costs anything. The work happens inside a Cowork session you already pay for, which also means it can read your repo and check the live site before it builds.
