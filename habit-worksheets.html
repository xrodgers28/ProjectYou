What is on this page

  • + habit sits on every section header row, in grey, so a habit is added straight into the right section.
  • Habit Tracker column (was "Do it with") and a new Auto tracked column showing which rows arrive on their own from Apple Health, Strava or Swarm.
  • Three row styles to choose from, in the toolbar: A rail, B fill, C box. Switch between them and tell me which one to keep.
  • Insights rewritten to say plainly what you get out of each habit, no soft language, and allowed to run long.
  • Sharpening my Creativity moved to Sense of Purpose and added to the Knowledge Graph as tenet T041. Keep the machine serviced renamed Physical Health Checkups.
  • All grey icon backgrounds removed, 14 of the 41 needed it.
  • Time Budget Dial replaces the old wheel label. Each section keeps its own slice of the circle, and the slice grows outward with how many habits you have switched on in it. Empty sections stay faint, so you can see both which of the seven are live and how heavily each one is loaded.
