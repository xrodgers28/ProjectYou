Architecture Map

v1.2

How the Project YOU Operating System is wired end to end, from where thoughts get captured, through the database and the scheduled jobs, to how every page is published and rendered. Read it top to bottom: inputs flow down into data, automation acts on the data, and the delivery pipeline turns it into the pages you use.

1 · Capture & InputsGetting things in
Drafts appDictated notes (Apple Watch / phone), the Task Capture pipeline reads the inbox and files each note.
Voice & text on-pageWeb Speech mics on Mission Control, Daily Habits, the board, write straight to the inbox.
StravaCardio activity synced into todos and the Quantified Self log, every 2 hours.
Apple HealthPushed off the phone hourly by Health Auto Export into health_metrics. Apple ships no cloud API, so that paid app is the only reason this feed exists. Apple Watch is the named source on most readings.
SwarmFoursquare check-ins, connected Aug 16, 2026 and backfilled to Apr 2009. 8,819 of them. Syncs 4 times a day into checkins, and fills the country map and the Trips timeline on Where I've Been.
▼
2 · DataSupabase, Postgres
Single source of truth. Most tables carry row-level security by email, and Realtime runs on the live boards. Four do not: build_recipe, overnight_build, pages_upload and publish_hook_log have RLS switched off and no policies. They hold build scratch and publish logs rather than personal data, so this is a deliberate gap rather than a leak, but it is a gap and the old wording on this page claimed otherwise.
todosToday's Tasks board, tasks, habits, est/act/log, rollover.
session_todosThe All ToDos running record (our chat work).
inboxCaptured notes awaiting routing.
qs_logQuantified Self master log; habits auto-log on tick.
daily_templateThe standing daily set behind the Daily Habits editor.
compass_questionsYear Compass prompts + hints.
content poolsAI deck tips / insights / platforms, Clever Phrases.
pagesEvery page's HTML (gzip+base64), the deploy source.
app_metaApp-level settings, flags and connector credentials.
checkinsEvery Swarm check-in, 8,819 of them, keyed on Foursquare's own id so a repeat pull cannot duplicate.
health_metricsApple Health readings, the largest feed in the system.
visited_countriesThe travel map. Real check-ins overwrite the unverified import.
staging_eventsEvery decision made at the Staging Area gate, which is what the learning metrics read.
session trackerssession_trackers, tracker and session_content: the nightly summary page and your answers on it.
▼
3 · Automation & Schedules2 database jobs and 9 scheduled Claude sessions
Two kinds of automation, and they are easy to confuse. pg_cron runs inside Postgres and can only touch the database. Scheduled tasks start a fresh Claude session with the full toolset.
Publish workflowSupabase pokes GitHub the moment a page row saves. Measured end to end at about 20 seconds. A version guard refuses to publish an older page over a newer one.
pg_cron, 2 jobsreset-daily-habits (4am ET) and ensure-ai-deck-daily (5am ET). These are the only two jobs running inside the database.
Task capture sweepEvery 2 hours. Drafts notes into the Staging Area, never straight onto a board.
Strava syncEvery 2 hours.
Swarm sync4 times a day, offset from the others.
Midnight Run4am ET. Works the overnight queue in build-and-report mode, never publishing.
Morning rundown5am ET, so the brief is waiting when you wake.
System Map freshness check3:15am ET. Read-only. Compares every map page on this site against the live database and files drift. It is why this page can be trusted.
Docs Library reconciliation2:30am ET.
Data Flow Map reconcile6am ET.
Community research scanEvery 3 days.
▼
4 · DeliveryFrom database to a rendered page
pages table → GitHubThe publish workflow mirrors HTML into the repo (xrodgers28/ProjectYou).
GitHub PagesServes and renders the HTML (Supabase's own domain returns plain text, so Pages is the render host).
Master navnav-config.js + navpatch.js, one config stamps the shared nav (and any sub-nav) onto every page.
▼
5 · PresentationThe pages you use, by nav group
Read from nav-config.js on origin/main, which is the only thing that decides the nav. There are five groups. The Parking Lot group this page used to list no longer exists.
