Session commands
[SC]

Status check

Where I am, plus what I need from you: in progress, open to-dos, done today, then quick questions and next steps to pick from. Read-only.

[RULE]

Save a standing rule

Say [RULE] then the instruction. I work out whether it is a global rule or one just for this project, write it to the right file, and tell you exactly where it landed. "From now on", "always" and "every time" still work the same way.

[VC]

Version check

A read-only sweep of every page on the site: version chips that disagree, chips missing, broken internal links. Reports a table and changes nothing. It also runs automatically inside [RAP].

[RAP]

End the session

Summary, settle hours, process to-dos, log accomplishments, then stop.

/morning

Morning brief

Your styled daily brief, on request or on a weekday schedule.

hardpull

Pull my Drafts now

Sweeps today's dictated Drafts notes into your Staging Area immediately, each with a suggested destination for you to approve or relabel. Otherwise it runs on its own every 2 hours.

Standing rules, always on 📌
from now on

Save a rule, in plain words

Say "from now on", "always", "every time" or "going forward" and I save it as a standing rule, then tell you the exact file and section it landed in. [RULE] does the same thing when you want to be explicit. I apply it in the session you say it, not just the next one.

everywhere

Change it everywhere

When a version number, title, date or count changes, it gets changed in every place it appears, then confirmed from the published page rather than from the copy I edited. Where a value shows in two places by design, one becomes the source of truth and the other reads from it. Duplicated values drift.

past only

Only what has happened

Nothing forward-looking in any tracker, page or document. Recorded fact, never intent, plan or prediction. A data source is judged on the completed events it can give us, not its headline feature.

same ask

Catch the repeat question

If you ask for something you have already asked for under a different name, I say so and show the overlap instead of quietly building a second version of it. Your call whether to merge, rename or keep both.

ask first

Never guess a term

If you use a phrase or name I do not understand, or that looks like a duplicate of one we already have, I ask rather than guessing or silently creating a second version.

no dash

No em-dashes, anywhere

Commas, colons or periods instead, in every deliverable. One named exception: Social Well-Being keeps its hyphen, because a database trigger matches that exact string.

EST

Everything stamped EST

Every time shown to you is America/New_York with the zone named. Pages derive it from an explicit timezone, never the browser clock.

self-check

Living docs check themselves

Anything that describes how a system works gets an automated nightly check against the live thing, and shows a Last verified date written by that check, never a rendering timestamp.

cost

Say when it costs

If an option I offer you costs money, the price is named inside that option before you pick, not discovered after the work is done.
